# 🏋️ Workout Challenger

Workout Challenger is a modern workout library web application that helps users explore exercises, view detailed workout information, save workouts, and create a personalized workout plan.

## 🚀 Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* DaisyUI
* React Icons
* React Toastify
* React Context API

## ✨ Key Features

1. **Workout Library**

   * Browse different workouts and exercises.
   * View information such as muscle group, equipment, duration, calories, and rating.

2. **Workout Details**

   * View detailed information about each workout.
   * See exercise instructions, difficulty, sets, repetitions, and other workout information.

3. **Save Workouts**

   * Add workouts to your saved list.
   * Remove individual workouts from the saved list.

4. **Personal Workout Plan**

   * Add workouts to your personal plan.
   * Manage and organize workouts for your training routine.

5. **Interactive Notifications**

   * Get instant toast notifications when adding or removing workouts.
   * Provides clear feedback for user actions.
